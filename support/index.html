FAQ & SUPPORT

A little help.
A clear next step.

Answers to the common questions, and a direct line when you need a hand.

Is AIM free?+

Free to download for now. There are no purchasing or account steps on this website. Availability may change in the future.

Which systems can run it?+

AIM is a Windows x64 desktop application. Use Windows 10 or Windows 11. macOS and Linux editions are not available.

What is the difference between installer and portable?+

The installer adds AIM to your Windows account with Start menu access. The portable ZIP runs from an extracted writable folder and keeps its data alongside the application.

Which sites and links work?+

AIM uses yt-dlp for supported public video and playlist links. Support depends on each source and can change. Private, login-only, and cookie-dependent media are outside the supported workflow.

Why does the first launch download tools?+

AIM uses yt-dlp for media extraction, FFmpeg / FFprobe for media processing, and Deno for JavaScript support. First-run setup downloads and verifies these tools automatically.

Setup failed. What should I do?+

Check your internet connection, confirm the app and download folders are writable, and retry setup. A checksum failure prevents that tool download from being activated. Report repeated failures through support.

Can I pause a download?+

Yes, during downloading. Pause retains partial files, and Resume / Retry attempts the transfer again. Some sites restart downloads. Merging and conversion stages cannot be paused.

Why is a format or quality missing?+

Available formats depend on the source. Choose a quality preset before adding a link; source formats determine the final result. MP4 compatibility requires the source to offer compatible codecs.

What happens to duplicate downloads?+

Choose Skip to avoid known duplicates, Keep both to save numbered filenames, or Replace to replace the existing completed file after the new result is ready.

How do I get updates?+

AIM checks the public GitHub release channel for app updates. You can also visit the Downloads or Releases page at any time. Tool updates are managed separately inside the app.

Does this website process my media?+

No. This website provides product information and links to GitHub downloads. Media analysis and downloads happen in the Windows application. The website has no account system, analytics, or upload form.

Can I use any video I find?+

Download only media you have permission to save. Respect the source website’s terms and the rights of content owners.
