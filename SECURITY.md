# Security reporting

Please report suspected vulnerabilities privately to [business.aliimranmalik@gmail.com](mailto:business.aliimranmalik@gmail.com), using the subject **AIM Downloader security report**.

Include the affected version or website page, a description of the issue, its potential impact, and steps to reproduce it safely. Do not send passwords, access tokens, personal downloads, or unrelated private data.

Avoid posting exploit details in public issues while the report is being assessed. A response time or bounty is not guaranteed.

Use the [latest stable release](https://github.com/malikali4129/AIM-DOWNLOADER-RELEASE/releases/latest) when checking whether an issue persists. Older releases may not receive fixes; this is not a promise of a maintenance period.

For ordinary bugs and feature requests, use [GitHub Issues](https://github.com/malikali4129/AIM-DOWNLOADER-RELEASE/issues/new/choose).
